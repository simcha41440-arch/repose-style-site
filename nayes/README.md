# נייעס סטטוס: רק מה ששווה לדעת

ערוץ מבזקים לציבור החרדי בסגנון **סטטוס**: מסך מלא, פסי התקדמות, לחיצה למבזק הבא,
כרטיסי סטטוס עם טבעת מחולקת לקטעים, ושורת "השב" עם לב ואימוג'י מהירים. "עורך" בינה מלאכותית אוסף, כותב, מדרג ומסנן את המבזקים לבד,
ואתה רק מאשר בלחיצה מהטלפון. כל המערכת בנויה סביב **מקום פרסום מרכזי ומיוחד**.

## מקומות הפרסום

| מיקום | איפה מופיע |
|---|---|
| 📌 **כרטיס ממומן** | בשורת כרטיסי הסטטוס במסך הראשי, במקום השני, הכי בולט |
| ✨ **סטטוס ממומן** | מסך מלא בצבעי המותג, אחרי כל 4 מבזקים, עם כפתור גדול לפעולה |
| 🖥️ **מודעת צד** | ליד מסך הסטטוס, למי שגולש מהמחשב |

לכל מודעה נספרים **חשיפות ולחיצות**, כך שיש לך נתונים להראות למפרסמים.
מנהלים הכל בלשונית "📣 פרסומות" בלוח הבקרה: יצירה, עריכה, השהיה, תאריכי קמפיין.
תמונה של מודעה עוברת אותה בדיקת AI מחמירה כמו תמונות של מבזקים.
את כתובת ההתקשרות למפרסמים מגדירים ב-`ADVERTISE_LINK` בקובץ `public/common.js`.

## רף האיכות
העורך האוטומטי נותן לכל מבזק **ציון חשיבות מ-1 עד 10**. מבזק עם ציון נמוך מ-`MIN_SCORE`
(ברירת מחדל 6) לא נכנס בכלל, אפילו לא לתור האישור שלך. רוצים ערוץ סלקטיבי יותר? מעלים ל-7.

## איך זה עובד

```
מקורות (RSS)  ──►  צינור אוטומטי כל 10 דקות  ──►  עורך AI  ──►  ממתינות לאישור  ──►  אתה מאשר  ──►  באתר
                     (GitHub Actions)              כותב מחדש,    + התראה בטלגרם      (/admin)
                                                    פוסל תוכן לא מתאים
הודעה מוואטסאפ  ──►  מדביקים בלוח הבקרה (לשונית "מבזק מהודעה")  ──►  אותו תהליך
```

**תמונות:** הצינור האוטומטי **לא מכניס תמונות בכלל**. תמונה נכנסת רק כשאתה מוסיף אותה בלוח הבקרה,
ואז היא עוברת בדיקת AI מחמירה. אם יש בה דמות של אישה או של ילדה, או שיש ספק, היא נפסלת ולא נשמרת.
האתר מעוצב כך שהוא נראה מצוין גם בלי תמונות.

## מבנה הקבצים

| קובץ | מה הוא עושה |
|---|---|
| `public/index.html`, `public/status.js` | מסך הסטטוסים וצופה המבזקים |
| `public/admin.html` | לוח הבקרה (`/admin`): מבזקים ופרסומות |
| `api/articles.js` | מגיש מבזקים ומקבל תגובות אימוג'י |
| `api/ads.js` | מגיש מודעות, סופר חשיפות ולחיצות |
| `api/admin.js` | לוח הבקרה: כניסה, אישור, עריכה, כתיבה מהודעה, בדיקת תמונה, ניהול מודעות |
| `api/_lib/ai.js` | **העורך הראשי**: ההנחיות לכתיבה ולסינון. כאן משנים סגנון וכללים |
| `pipeline/run.mjs` | הצינור האוטומטי שרץ כל 10 דקות |
| `pipeline/sources.json` | **רשימת המקורות**. כאן מוסיפים מקורות |
| `schema.sql` | מבנה מסד הנתונים |

## הפעלה, צעד אחר צעד (כשעה, פעם אחת)

### 1. ריפו נפרד ב-GitHub
כרגע התיקייה יושבת בתוך הריפו של החנות. צור ריפו חדש (למשל `nayes`) והעבר אליו את **תוכן** התיקייה
`nayes/`, כך ש-`package.json` יהיה בשורש. בלי זה הצינור האוטומטי לא ירוץ.

### 2. מסד נתונים: Supabase (חינם)
1. פתח פרויקט חדש ב-supabase.com.
2. SQL Editor ← New query ← הדבק את כל `schema.sql` ← Run.
3. Project Settings ← API: העתק את **Project URL** ואת **service_role key**. את המפתח הזה אסור לחשוף לאף אחד.

### 3. מפתח AI: Anthropic
console.anthropic.com ← API Keys ← Create Key. מומלץ להגדיר שם תקרת הוצאה חודשית.

### 4. אחסון: Vercel
1. Add New Project ← בחר את הריפו החדש.
2. Environment Variables:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ANTHROPIC_API_KEY`
   - `ADMIN_PASSWORD`: סיסמה חזקה ללוח הבקרה
   - `SESSION_SECRET`: מחרוזת אקראית ארוכה (לא חובה, אבל מומלץ)
3. Deploy. האתר באוויר, ולוח הבקרה בכתובת `/admin`.

### 5. הצינור האוטומטי: GitHub Actions
בריפו: Settings ← Secrets and variables ← Actions:
- **Secrets:** `ANTHROPIC_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, ולא חובה: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
- **Variables:** `SITE_URL` (כתובת האתר), ולא חובה: `AUTO_PUBLISH` = `true`, `MIN_SCORE` (רף האיכות)

אחר כך בלשונית Actions ← "צינור חדשות" ← Run workflow, כדי לבדוק שהכל עובד.

### 6. התראות לטלפון בטלגרם (מומלץ)
1. בטלגרם שלח `/newbot` ל-@BotFather וקבל טוקן. זה `TELEGRAM_BOT_TOKEN`.
2. שלח הודעה כלשהי לבוט החדש, ואז פתח בדפדפן
   `https://api.telegram.org/bot<הטוקן>/getUpdates` והעתק את המספר שמופיע ב-`chat.id`. זה `TELEGRAM_CHAT_ID`.

### 7. מקורות
ערוך את `pipeline/sources.json`. לכל מקור יש `name`, `url` (כתובת פיד RSS) ו-`enabled: true`.
אפשר לקבע `category` (למשל `local`) ו-`city` לכל מקור.
מקורות טובים להתחלה: הודעות דוברות של משרדי ממשלה, עיריות, משטרה, כבאות ומד"א, חברות תחבורה, וגופים ציבוריים.

## פרסום אוטומטי מלא
ברירת המחדל היא שכל מבזק מחכה לאישורך. כשתסמוך על העורך, הגדר `AUTO_PUBLISH=true`.
גם אז, מבזק שהעורך כתב לגביה הערות (ספק או רגישות) **לא** תתפרסם לבד ותחכה לך.

## עלויות משוערות
- Vercel, Supabase, GitHub Actions: חינם בהתחלה.
- AI: כ-3 עד 5 סנט למבזק. 100 מבזקים ביום הן בערך 90 עד 150 דולר בחודש.
  מבזקים שנפסלו נשמרות כדי לא לשלם עליהן שוב. אפשר להוזיל עם `AI_MODEL` (מודל זול יותר), במחיר של איכות כתיבה.
